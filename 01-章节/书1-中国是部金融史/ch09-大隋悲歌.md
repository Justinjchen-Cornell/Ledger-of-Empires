## 2. 三幕故事

### 第一幕：隋文帝的制度创新（困局 → 抉择 → 代价）

**困局**：南北朝分裂/士族/官僚/战乱；隋朝立国；突厥；经济凋敝。

**抉择**：隋文帝：

- 科举/三省/开皇律/裁撤郡县/考核/门下省行贿测试；干部队伍/权力制衡。
- 输籍法/均田/义仓；纳税农户 410 万→890 万；开垦 5585 万顷。
- 隋五铢：2.42 克/各县自铸/父老议定；1,255 县统一；官铸/私铸/罚没；阔边直笔五铢（关陇士族供奉/回炉）。
- 重商/无为而治；科技/商业/城市；869 部科技图书；赵州桥。

**代价**：开皇之治/富强；但需要时间/干部/稳定；隋炀帝的扩张/区域掠夺 → 亡。

### 第二幕：隋炀帝的国际贸易/大运河（繁荣 → 抉择 → 代价）

**困局**：西突厥/吐谷浑/高丽；江南/江北；关陇士族/江南商人；大运河；三征高丽。

**抉择**：隋炀帝：

- 国际贸易/比较优势/补贴/分化西突厥/吐谷浑；但官僚经商/鸟毛/毛驴。
- 大运河：帝国政府/无偿劳役/成本压在江北；民夫/死亡；官僚腐败（麻叔谋/人肉羹）。
- 三征高丽：损北补南；民夫/士兵；杨玄感/流民/关陇士族。
- 白钱/告缗：打击关陇士族；但失去统治基础。

**代价**：江北赤贫/流民/关陇士族反叛/隋亡。

### 第三幕：白钱/告缗/隋亡（危机 → 抉择 → 代价）

**困局**：关陇士族/江南商人；白钱/隋五铢；三征高丽；流民/杨玄感；隋炀帝退守江都。

**抉择**：隋炀帝：

- 白钱/全国赋税用白钱；告缗/揭发长官；打击关陇士族。
- 退守江都/骁果军/括寡妇配兵；宇文化及/隋炀帝被杀。

**代价**：关陇士族反叛/骁果军/宇文化及/隋亡。

## 3. 决策点

### 决策点 1：隋文帝优先做什么？

- 选项 A：科举/文官/三省/开皇律（控制官僚/阶层流动）
- 选项 B：输籍法/均田/义仓（土地/税基/粮食）
- 选项 C：隋五铢/统一货币/重商（市场/货币）
- 选项 D：战争/扩张/大运河（工程/军事）
- 历史选择：A + B + C
- 结果：开皇之治/富强；但隋炀帝的 D → 亡。

### 决策点 2：隋炀帝怎么处理大运河/三征高丽/区域？

- 选项 A：帝国政府修运河/无偿劳役/三征高丽（隋炀帝式）
- 选项 B：商人修运河/特许经营/市场化
- 选项 C：轻徭薄赋/区域平衡/不三征高丽
- 选项 D：依靠关陇士族/江南商人平衡
- 历史选择：A + 三征高丽 + 白钱/告缗
- 结果：民夫/死亡/流民/关陇士族反叛/隋亡。

### 决策点 3：隋炀帝怎么处理关陇士族/江南商人/危机？

- 选项 A：白钱/告缗/打击关陇士族（隋炀帝式）
- 选项 B：依靠关陇士族/回长安/正统
- 选项 C：依靠江南商人/退守江都/割据
- 选项 D：轻徭薄赋/区域平衡/妥协
- 历史选择：A + C
- 结果：关陇士族反叛/骁果军/宇文化及/隋亡。

## 4. 五层追问

### 事实层

隋文帝为什么科举/均田/隋五铢？隋炀帝为什么大运河/三征高丽/白钱/告缗？隋朝为什么三十八年而亡？

### 机制层

制度创新 = 国家能力（科举/文官/三省/开皇律/输籍法/均田/义仓/隋五铢/重商）；公共工程/战争财政 = 谁承担成本/谁受益；区域掠夺/告缗 → 失去统治联盟；改革/扩张不能把统治基础推到对立面。

### 反事实层

如果隋炀帝不搞大运河/三征高丽？如果商人修运河/特许经营？如果轻徭薄赋/区域平衡？如果依靠关陇士族/江南商人平衡？

### 映射层

科举/文官 → 高考/公务员/阶层流动；均田/义仓 → 土地改革/粮食储备/社会保障；隋五铢/白钱 → 货币统一/通胀/货币战争；大运河/三征高丽 → 基建/战争财政/区域转移支付；关陇士族/江南商人 → 利益集团/区域利益/联盟。

### 失效层

古代农业帝国 vs 现代国家；隋朝的区域/士族/府兵 vs 现代；没有央行/法治；不能把“大运河/三征高丽/白钱/告缗”直接类比今天的基建/战争/货币政策。

## 8. 核心总结：改革不能失去统治联盟

（说明：以下是历史机制的启示，不是政策预测或政策评价；不构成投资建议。）

### 一句话

隋朝的悲剧不是“没钱”，而是“有钱/有制度/有工程，却失去了统治联盟”；改革/扩张/区域掠夺，不能把统治基础推到对立面。

### 三个机制

**机制一：制度创新 = 国家能力。**

- 科举/文官/三省/开皇律/裁撤郡县/考核/门下省行贿测试；干部队伍/权力制衡。
- 输籍法/均田/义仓；纳税农户 410 万→890 万；开垦 5585 万顷；含嘉仓。
- 隋五铢：2.42 克/各县自铸/父老议定；1,255 县统一；官铸/私铸/罚没。
- 重商/无为而治；科技/商业/城市；869 部科技图书；赵州桥。

**机制二：公共工程/战争财政 = 谁承担成本/谁受益。**

- 帝国政府/无偿劳役：成本压在江北/最弱势群体；民夫/死亡/官僚腐败。
- 商人/特许/市场化：成本分摊/激励兼容；美国伊利运河的例子。
- 区域政策/联盟：江南获益/江北受损；关陇士族/江南商人；隋炀帝把北方推到对立面。

**机制三：改革/扩张不能失去统治联盟。**

- 隋炀帝的白钱/告缗/区域掠夺/三征高丽 → 关陇士族反叛。
- 退守江都 → 失去正统/骁果军；宇文化及/隋炀帝被杀。
- 隋亡；唐兴。

### 用财政能力公式看隋朝

| 人物 | 收入工具 | 执行系统 | 政治联盟 | 结果 |
|---|---|---|---|---|
| 隋文帝 | 科举/均田/义仓/隋五铢/重商 | 三省/开皇律/干部 | 关陇士族/小农/商人 | 开皇之治/富强 |
| 隋炀帝 | 白钱/告缗/三征高丽/大运河 | 官僚/江南商人 | 江南商人/南人/骁果军 | 关陇士族反叛/隋亡 |

### 隋炀帝如果重来一次

- **不搞区域掠夺/白钱/告缗**：不要把统治基础（关陇士族）推到对立面。
- **商人修运河/特许经营/市场化**：成本分摊/激励兼容；不要无偿劳役。
- **轻徭薄赋/区域平衡**：江南/江北都受益；不要“损北补南”。
- **不三征高丽/有限战争**：战争目标有限；不要把民力耗尽。
- **回长安/正统**：不要退守江都/割据；保持正统/联盟。
- 一句话：**改革/扩张的目的是“养未来”，不是“抢现在”；失去统治联盟，再富强的帝国也会速亡。**

### 现代类比

- 科举/文官 → 高考/公务员/阶层流动；教育→文明→制度→科技→财富。
- 均田/义仓 → 土地改革/粮食储备/社会保障。
- 隋五铢/白钱 → 货币统一/通胀/货币战争；区域掠夺/告缗。
- 大运河/三征高丽 → 基建/战争财政/区域转移支付；谁承担成本/谁受益。
- 关陇士族/江南商人 → 利益集团/区域利益/联盟；改革不能失去统治基础。

### 对企业的三条建议

1. **公共工程/大项目：先算“谁承担成本、谁受益”**；无偿/隐性成本会反噬。
2. **改革/扩张不能失去核心联盟**：关陇士族/江南商人；企业里的核心团队/渠道/股东。
3. **货币统一/白钱/告缗**：短期有效，长期摧毁信任；稳定/渐进/信用。

### 对投资者的三条建议

1. **基建/战争财政/区域转移支付**：关注成本/受益/联盟；不要只看“富强”。
2. **货币统一/通胀/告缗**：短期利好名义资产，长期摧毁信用；不要用旧周期估值。
3. **利益集团/区域利益/联盟**：改革/扩张的政治风险；关注“谁被推到对立面”。

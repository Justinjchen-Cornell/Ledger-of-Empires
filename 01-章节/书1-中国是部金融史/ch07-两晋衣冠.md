## 2. 三幕故事

### 第一幕：司马炎的占田制（困局 → 抉择 → 代价）

**困局**：西晋建立，士族高门把持官位/土地/军队/铸币；皇帝是橡皮图章；石崇炫富；土地兼并/流民。

**抉择**：司马炎的选择：卖官（但选官由士族“郡姓”集体推荐，皇帝说了不算）；占田制——部曲脱离士族可得七十亩，士族还田（一品五十顷），三十税一，占田农民承担兵役。

**代价**：太康之治——民户从 245 万增至 377 万，小农经济恢复；但士族反扑，司马衷/贾后/八王之乱；五胡十六国。

### 第二幕：东晋的“二桃杀三士”——铸币权特许（困局 → 抉择 → 代价）

**困局**：东晋初，江南豪门（吴兴沈氏/义兴周氏）私铸/私兵；皇权弱；北方士族/侨郡；需要稳固统治。

**抉择**：司马睿把铸币权特许给吴兴沈氏，挑拨沈氏/周氏；同时开山泽之禁、土断、侨郡、培养小农经济。

**代价**：沈氏/周氏内斗，两败，江南豪门衰落；东晋皇权暂时稳固；但士族问题未根本解决；桓温/刘裕。

### 第三幕：桓温的废货币/庚戌土断/寒门教育（危机 → 抉择 → 代价）

**困局**：东晋货币奇缺/剪边五铢/沈郎钱；士族高门 hold 古钱/土地/部曲；皇权弱；前秦威胁。

**抉择**：桓温想废货币（以谷帛为币），被孔琳之驳斥；转而搞庚戌土断（清理士族隐匿民户/土地），寒门教育，北府兵，北伐。

**代价**：废货币失败；庚戌土断成功；寒门教育/北府兵 → 淝水之战/东晋重生；但桓温篡位未成；刘裕代晋。

## 3. 决策点

### 决策点 1：司马炎面对士族，选哪条？

- 选项 A：占田制/土断/低税/兵役（培养小农，削弱士族）
- 选项 B：依靠士族/分权/卖官
- 选项 C：铸币权特许/挑拨士族（二桃杀三士）
- 选项 D：强皇权/中央军/科举/教育
- 历史选择：A（占田制）
- 结果：太康之治；但士族反扑/八王之乱/五胡。

### 决策点 2：司马睿面对江南豪门，选哪条？

- 选项 A：铸币权特许/挑拨（二桃杀三士）
- 选项 B：直接削藩/建中央军
- 选项 C：土断/开山泽/小农经济
- 选项 D：依靠豪门/分权
- 历史选择：A + C
- 结果：豪门衰落/小农经济/东晋稳定；但士族问题未根本解决。

### 决策点 3：桓温面对士族，选哪条？

- 选项 A：废货币（以谷帛为币）
- 选项 B：庚戌土断/清理隐匿民户
- 选项 C：寒门教育/北府兵
- 选项 D：官铸货币/中央军
- 历史选择：A（失败）+ B + C
- 结果：土断/寒门教育/北府兵成功；废货币失败；东晋重生；桓温未篡。

## 4. 五层追问

### 事实层

司马炎为什么搞占田制？东晋为什么特许铸币权？桓温为什么废货币？庚戌土断为什么成功？北府兵为什么能打赢淝水？

### 机制层

占田/土断 = 皇权培养小农/削弱士族；铸币权特许/金融牌照 = 皇权挑拨豪门/以夷制夷；货币制度不能休克疗法；寒门教育/阶层流动 = 教育→文明→制度→科技→财富；集权/分权循环。

### 反事实层

如果司马炎有更多时间/中央军/教育？如果司马睿直接削藩？如果桓温不废货币/用官铸？如果刘裕不北伐？

### 映射层

集权 vs 分权 → 国家能力 vs 市场活力；占田/土断 → 土地改革/房地产税/户籍/保障房；铸币权特许/金融牌照 → 牌照/特许经营/金融监管；废货币 → 货币改革/休克疗法/价格管制；寒门教育 → 教育公平/阶层流动；集权/分权循环 → 国家能力/市场活力/外族威胁。

### 失效层

古代农业帝国 vs 现代国家；两晋的士族/豪门 vs 现代企业/地方；没有央行/法治；不能把“占田制/废货币”直接类比今天的土地/货币改革。

## 8. 核心总结：集权与分权的循环

（说明：以下是历史机制的启示，不是政策预测或政策评价；不构成投资建议。）

### 一句话

集权→官铸→击溃异族→经济衰退；分权→私铸→经济兴盛→异族入侵；集权与分权没有绝对对错，关键是国家能力、土地、教育、联盟的平衡。

### 三个机制

**机制一：占田/土断 = 皇权培养小农/削弱士族。**

- 司马炎占田制：部曲七十亩、士族还田、三十税一、兵役；太康之治，民户 245 万→377 万。
- 但士族反扑，司马衷/贾后/八王之乱；五胡十六国。
- 东晋土断/开山泽/寒门教育 → 北府兵/淝水之战；桓温庚戌土断成功。
- 土地改革需要皇权/干部/军队/时间/联盟；缺一不可。

**机制二：铸币权特许/金融牌照 = 皇权挑拨豪门。**

- 司马睿把铸币权特许给吴兴沈氏，挑拨沈氏/周氏；“二桃杀三士”。
- 金融牌照是最值钱的东西；牌照不创造财富，但可以获得财富的使用权。
- 但牌照创造租金/内耗；长期需要中央军/土断/教育；否则豪门衰落，士族仍在。

**机制三：货币制度不能休克疗法。**

- 桓温想废货币（谷帛），被孔琳之驳斥；货币承载千年经济，不能一道诏书废弃。
- 剪边五铢/沈郎钱/货币奇缺；货币减凿 = 财富再分配。
- 货币改革需要稳定/渐进/信用；休克疗法会制造黑市/替代货币。

### 两晋如果重来一次

- **司马炎**：占田制 + 中央军 + 寒门教育 + 土断 + 时间；不能只靠占田/卖官。
- **司马睿**：铸币权特许 + 土断 + 寒门教育 + 北府兵；但不要只靠挑拨。
- **桓温**：不废货币；用官铸/稳定货币 + 土断 + 教育 + 北府兵；渐进。
- 一句话：**货币制度不能一道诏书废弃；教育是阶层流动的根；土地改革需要皇权/干部/军队/时间。**

### 现代类比

- 集权 vs 分权 → 国家能力 vs 市场活力；中国/西欧路径。
- 占田/土断 → 土地改革/房地产税/户籍/保障房；需要中央-地方/干部/时间。
- 铸币权特许/金融牌照 → 牌照/特许经营/金融监管；牌照是最值钱的东西；挑拨/以夷制夷；但 rent-seeking/内耗。
- 废货币 → 货币改革/休克疗法/价格管制；货币制度不能一道诏书废弃；稳定/渐进/信用。
- 寒门教育/阶层流动 → 教育公平/科举/高考/阶层固化；教育→文明→制度→科技→财富。
- 集权/分权循环 → 国家能力/市场活力/外族威胁；没有绝对对错。

### 对企业的三条建议

1. **牌照/特许是护城河，也是政治风险**：不要只靠牌照；建能力/教育/组织。
2. **土地/土断/保障房**：需要皇权/干部/军队/时间；不是“分地”那么简单。
3. **货币制度不能休克疗法**：稳定/渐进/信用；不要押注“废货币/换锚”。

### 对投资者的三条建议

1. **集权/分权/货币制度/牌照**：关注国家能力/货币信用/阶层流动；不要押注休克疗法。
2. **牌照经济**：短期护城河，长期政治风险；关注监管/竞争/特许权变化。
3. **教育/阶层流动**：教育公平/阶层固化，影响长期增长/社会稳定；关注教育政策。

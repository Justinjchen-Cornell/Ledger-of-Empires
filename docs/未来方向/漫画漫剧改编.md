# 未来方向：漫画 / 漫剧改编

> 本期（M1-M4）不做。只记录需求，保留接口。

## 为什么现在记录

- 章节包/故事 JSON 已经是“故事圣经 + 分支脚本”，可以直接改成分镜/台词。
- 亲子线“砖砖”天然适合漫画/动画。
- 漫画/漫剧可以作为课程/社群的引流产品，或独立 IP。

## 现在保留的接口

- **章节包**：三幕故事、决策点、人物、数字、原文摘句。
- **故事 JSON**：`scenes / choices / next / reveal`；未来可加 `characters`、`setting`、`visual`、`dialogue`、`panels`、`sfx`。
- **卡片**：机制/当代对照/失效条件，是每章的“主题”。

## 未来格式

- **漫画**：分镜脚本（页/格/画面/台词/旁白/音效）。
- **漫剧**：场景/镜头/旁白/对白/音效/时长（30-90 秒/集）。
- 先做 1 集 3-5 分钟的“管仲的刀”或“砖砖的钱变小了”样片。

## 版权

- 书是版权作品；改编要原创化：原创对白/画面，短引文 + 出处，不复制原书大段文字/图片。
- 历史人物/事件是公共领域；但书的表达/论证要转化。
- 漫画/漫剧的版权归项目方；如引用原书，标注出处。

## 不在本期

- 不做分镜、不做画稿、不做配音、不做视频。
- 等 M4 课程/工作台上线后，再评估是否启动。

## 1. 目标

用《中国是部金融史》1+2（周→明，24 章）做一次完整的学习 + 产出：

- **学**：每章通过三幕故事 + 五层追问 + 动手建模，掌握“财政—货币—土地”的因果链。
- **产**：24 张决策卡、8 个内核、12 篇文章、3 讲小课、B2B 课件、公开工作台、8 个亲子故事。
- **变现**：首期小课 + B2B 内训 + 社群转化。

**成功标准**

1. 24 章全部完成，每章通过验收门。
2. 24 张卡签字，8 个内核归档。
3. Excel + Python 模型可复现、可交叉校验。
4. 工作台上线，3 个陌生人能独立跑通一次推演。
5. 首期小课 ≥15 人，NPS ≥8。
6. 8 个亲子故事 + 8 张规则卡 + 游戏规则。
7. 1 页 CV/LinkedIn 项目说明。

## 3. 学习闭环

### 3.1 每章流程

```
你说“继续”
→ 我发本章章节包（三幕故事 + 2-3 个决策点 + 原文摘句）
→ 你选 / 答（10-15min）
→ 我揭晓历史 + 五层追问（10-15min）
→ 建模段（10-15min，你动手 / 我给脚手架）
→ 我出卡片草案 + 学习日志 + 亲子故事（5min）
→ 你改三处、签字
→ commit + 更新进度表
→ 等你下一次“继续”
```

每章用户投入 35-50 分钟。24 章约 18-20 小时。

### 3.2 三幕故事

1. **困局**：场景、人物、数字、原文一句。
2. **抉择**：当时能走的 2-3 条路，用户先选。
3. **代价**：历史真实选择 + 短期结果 + 长期结果。

### 3.3 五层追问

1. **事实层**：发生了什么？
2. **机制层**：为什么必然走到这一步？
3. **反事实层**：如果换一条路，会怎样？
4. **映射层**：今天哪里在重演？
5. **失效层**：哪里不可比？

每层一个问题，用户答完再加一层。聊到第 5 层，卡片自动成形。

### 3.4 建模段

- 第 1-6 章：搭 A 模型骨架（财政缺口 → 融资方式 → 违约年份）。
- 第 7-12 章：加 B 模型（货币贬值 → 物价 → 铸币税）。
- 第 13-24 章：复用、校准、做情景库。
- 默认分工：用户动手推导公式、写核心代码；我提供数据、脚手架和 review。
- 未动手的章节，卡片标记 `hands_on: false`。

### 3.5 卡片

每张卡 12 个字段：

```
编号/朝代/年份
处境：财政缺口 or 外部冲击
约束：税基 / 军事 / 信息 / 执行
选项：当时能走的 2-4 条路
决策与结果：短期 / 长期
代价：显性 / 隐性
机制：为什么必然走到这一步
反事实：换一条路会怎样
当代对照：1-2 条
失效条件：≥3 条不可比
我的异议：作者可能忽略了什么
证据：A 正史原文 / B 书内推断 / C 现代估算 + 原文行号
```

卡片使用 YAML frontmatter，便于后续站点和检索：

```yaml
---
id: K01-01
kernel: K01
dynasty: 西汉
year: -186
title: 吕后大通胀（荚钱）
evidence_grade: A
source_lines: [1634, 1665, 1779]
hands_on: true
status: draft
---
```

### 3.6 亲子彩蛋

- 只有命中 8 个儿童内核之一才做，不硬凑。
- 3-5 分钟故事 + 1 个选择 + 1 句道理。
- 故事是成人卡片的费曼测试：4 岁孩子听不懂，说明机制没抽干净。

## 5. 数据与模型

### 5.1 数据分层

| 层级 | 内容 | 来源 | 用法 |
|---|---|---|---|
| A 硬锚点 | 铸币重量/成色、米价、人口、田赋、军费、纸币发行量 | 正史食货志、出土、学术汇编 | 校准模型 |
| B 区间估计 | 税率、货币流通量、GDP、官俸占比 | 学术研究 | 给范围，不给点值 |
| C 现代真实数据 | GDP、财政收支、M2、土地出让金、外储 | World Bank、国家统计局、Wind | 当代对照、模型校准 |

C 层已验证可访问：World Bank API、国家统计局网站。

### 5.2 数据表

`03-数据/processed/` 下固定 5 张表：

1. `dynasty_master.csv`
   - `period_id, dynasty, start_year, end_year, currency_regime, land_system, tax_system, notes`
2. `fiscal_annual.csv`
   - `period_id, year, revenue_land, revenue_poll, revenue_commerce, revenue_monopoly, expense_military, expense_salary, expense_court, expense_tribute, expense_public_works, deficit, financing_method, source_id, evidence_grade`
3. `money_series.csv`
   - `period_id, year, coin_name, weight_g, fineness, nominal_value, issue_volume, price_index, silver_copper_ratio, source_id, evidence_grade`
4. `price_series.csv`
   - `period_id, year, good, unit, price_nominal, price_grams_silver, source_id, evidence_grade`
5. `modern_series.csv`
   - `year, gdp, fiscal_revenue, fiscal_expenditure, m2, land_sale_revenue, external_reserves, source`

`sources.md` 是唯一出处登记表，每个 `source_id` 对应：作者、书名/报告、年份、页码/URL、证据等级、备注。

### 5.3 模型

**Excel：`王朝资产负债表.xlsx`**

- `总表`：收入、支出、缺口、融资方式、违约年份。
- `K01`-`K08`：每个内核一张分表。
- `情景`：3 个预设情景（基线 / 战争 / 白银断流）。
- `敏感性`：税率、军费、铸币成色、发行量四个变量的双向表。
- `数据字典`：字段、单位、来源。

**Python：`04-模型/python/`**

- `data_pipeline.py`：读取、清洗、校验 CSV，输出 `processed/`。
- `balance_sheet.py`：`fiscal_gap()`、`financing_options()`、`default_year()`、`run_scenario()`。
- `money_model.py`：`seigniorage()`、`inflation()`、`confidence_threshold()`。
- `scenarios.py`：`monte_carlo()`、`sensitivity()`。
- `charts.py`：物价曲线、赤字曲线、情景对比图。

**交叉校验**

- 3 个预设情景，Excel 与 Python 的违约年份、缺口、通胀率差异 < 1%。
- 校验脚本：`04-模型/python/tests/test_cross_validation.py`。

**模型卡**

每个模型一张 `model-card.md`：假设、公式、校准数据、局限、失效条件、历史回测。

**历史回测（定性）**

- 王莽币改 → 通胀 + 信用崩溃。
- 大明宝钞 → 超发 → 民间拒用。
- 唐末两税法 → 钱荒 + 通缩。
模型至少要能复现这三条方向性结论。

### 5.4 数据质量

- 每行必须有 `source_id` + `evidence_grade`。
- 缺失值只能写 `null`，并在 `notes` 说明原因。
- 单位统一：石、文、两、克、年。
- `data/raw/` 只读，不入库修改；清洗逻辑写在 `data_pipeline.py`。
- 每个数据点在 `sources.md` 有唯一 ID。

### 6.5 工作台
